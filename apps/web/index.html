what's real

Not a demo. Not mocked panels.

Every panel below is wired to real behavior, not a screenshot pretending to be a product.

The real Monaco editor

The same editing engine behind VS Code. A genuine TypeScript language service, not a reimplementation, plus syntax highlighting for two dozen more languages.

A real terminal

xterm.js over a real shell. Readline editing, history, and Tab completion, executing files for real and streaming their output back.

Real Git

isomorphic-git in a worker. Commit, branch, diff, push, and pull, with an inline Source Control panel.

A real filesystem

OPFS-backed and persistent. Your files are yours from the first keystroke, no upload required.

Cloud execution, optional

Python, C, C++, Java, Go, and Rust run in a sandboxed container when you need a real compiler. JS and TS run locally, no network required.

how it works

Local-first, in the actual order of operations

01

Open a tab

OPFS gives you a real, persistent filesystem instantly. No install, no account, no loading screen.

02

Edit, run, commit

Real Monaco, a real shell, real Git, all operating on files that live in your browser.

03

Reach for the cloud if you need it

A real compiler for C++ or Java is one command away, and entirely optional.

04

Close the tab, come back later

Your workspace and open tabs auto-restore on reload, even offline.
