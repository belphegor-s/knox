How it works

Local-first isn't a slogan here — it's the actual order of operations.

Open a tab

OPFS gives you a real, persistent filesystem instantly — no install, no account, no loading screen waiting on a server.

Edit, run, commit

Real Monaco, a real shell, real Git — all operating on files that live in your browser, not on a remote disk.

Reach for the cloud only if you need it

Need a real compiler for C++ or Java? Cloud execution is one command away — and entirely optional.

Close the tab, come back later

Your workspace, open tabs, cursor position, and layout all auto-restore on reload — even offline.

Looks right, day or night

Every surface — editor, terminal, panels — follows your system theme, with no separate "dark mode" bolted on after the fact.
