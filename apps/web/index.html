A real terminal

A full Linux shell in the same container as your files, not an emulation of one. Install packages, run a compiler, use whatever's already on the box.

Real Git

VS Code's own Source Control panel, backed by a real git binary. Commit, branch, diff, push, and pull - the same as typing it in a terminal.

A real filesystem

Every file lives in the session's own container, not synced up from your machine. Self-hosted, it persists on a real Docker volume across restarts.

Isolated per session

The public demo runs each session in its own container, torn down the moment it ends. Self-host it and there's no isolation boundary to think about - it's just yours.
